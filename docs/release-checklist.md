# v1.0 release checklist

Audited 2026-11-04 against commit `a64f767` and later. Every item was checked against the code
and by running it; nothing is marked from memory. **PASS** = verified, with the evidence named.
**FIXED** = was failing, fixed during the audit, now verified. **DEVIATION** = works, but
differently from the original plan, with the reason. Test names are Vitest unless marked e2e
(Playwright, `npm run e2e`).

Note: the brand kit lives in `logo-assets/` (there is no `axlebook-brand-kit/` directory).

## Summary

| Area                       | Result                                                                 |
| -------------------------- | ---------------------------------------------------------------------- |
| Unit and integration tests | 294 / 294 pass (SQLite)                                                |
| Postgres 17                | 183 / 183 server tests pass, the same set as on SQLite                 |
| Browser tests              | 17 / 17 pass (desktop and phone)                                       |
| Domain coverage            | 100% lines, branches, functions and statements, enforced in CI         |
| axe                        | 0 serious or critical issues on 14 pages, light and dark               |
| npm audit (production)     | 0 vulnerabilities                                                      |
| Docker                     | healthy on :8080, 319 MB, data survives restart, works with no network |

Bugs found and fixed during the audit: backups dropped inspections; shared users could list a
vehicle's other shares; passwords used scrypt below OWASP's current cost; validation errors
contained English sentences; SSO failed with an http identity provider; garage card markup was
invalid for screen readers; a link relied on colour alone; the header scrolled sideways at
768px; page titles overlapped when they wrapped; hour-meter and electric vehicles plotted as
0 mpg in reports; missing asset files returned the app page instead of 404.
